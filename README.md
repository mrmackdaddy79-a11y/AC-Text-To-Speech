# AC Text To Speech

A lightweight, clutter-free Text-to-Speech Decal plugin for Asheron's Call. Keep your eyes on the action (or step away from the screen entirely) while never missing an important message.

## Features
* **Hear Friends & Vendors:** Automatically reads direct tells and standard chat channels (General, Trade, LFG, Allegiance, Fellowship, Patron, and Vassals).
* **Customizable Voices:** Runs efficiently on the built-in Windows Text-to-Speech engine. To change the accent or voice, simply change the default voice in your Windows OS Settings!
* **No Spell-Cast Spam:** Intelligently ignores local chat to keep repetitive spell words and combat spam out of your ears.
* **Smart Name Memory:** If a player or NPC sends you multiple lines in a row, the plugin remembers them and skips repeating their name for 15 seconds.
* **Clean Audio:** Automatically strips out hidden XML and hyperlink formatting so the dialogue sounds completely natural.
* **Multitasking Friendly:** Hear when your allegiance or a buyer needs you, even if you are alt-tabbed out of the game.

## Installation
1. Go to the **Releases** section on the right side of the GitHub page.
2. Download the latest `ACTextToSpeech.dll` file.
3. Place the downloaded `.dll` into your `Decal Plugins` folder.
4. Open Decal, click **Add**, and browse to the `.dll` to register it. 

## Commands
* `/tts on` - Enables speech (provides a chat box and audio confirmation).
* `/tts off` - Disables speech.
